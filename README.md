# Apple_project
This project is a responsive clone of Apple's official website, developed as part of my front-end web development studies with Evanadi Tech. The goal was to replicate Apple's clean design, navigation structure, and product showcase sections using HTML and CSS.

Features
✅ Responsive Navigation Bar - Mimics Apple's main menu with product categories and search/cart icons
✅ Product Highlight Sections - Showcases key Apple products (MacBook Pro, iPhone 11 Pro, etc.)
✅ Dual-Column Layout - For Watch Series 5 and Apple Card promotions
✅ Comprehensive Footer - With legal disclaimers, multi-column links, and copyright info
✅ Apple-like Styling - Clean typography, spacing, and visual hierarchy

Technologies Used
HTML5 (Semantic structure)

CSS3 (Flexbox, responsive design)

Font Awesome (Icons)

Mobile-First Approach

Key Learning Points
Studied Apple's minimalist design philosophy

Implemented complex multi-section layouts

Practiced CSS positioning and flexbox

Recreated Apple's footer with nested link columns

Learned to handle trade-in disclaimers and legal text

How to Use
Clone this repository

Open Apple.html in any modern browser

(Optional) Link to the companion Apple.css file for full styling
